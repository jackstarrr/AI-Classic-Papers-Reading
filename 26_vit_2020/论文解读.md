# An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

## 基本信息

- 编号：26
- 分类：视觉 Transformer
- 作者：Alexey Dosovitskiy et al.
- 年份：2020
- 原稿来源：https://arxiv.org/pdf/2010.11929
- 建议代码主题：实现图像 patchify 和位置编码

## 为什么值得读

ViT 把图像切成 patch 后输入 Transformer，改变视觉模型设计路线

## 问题背景

Transformer 在 NLP 中成功后，研究者尝试把同样结构迁移到视觉任务。

## 核心思想

把图像切成固定大小 patch，当作 token 序列输入 Transformer 编码器。

## 模型/算法结构

每个 patch 线性投影为 embedding，加位置编码和 class token 后进入 Transformer。

## 对 AI 体系结构的影响

ViT 证明在足够数据和算力下，纯 Transformer 可以成为强视觉 backbone。

## 局限与后续发展

数据需求较高，小数据上不如 CNN 归纳偏置强，计算也随 token 数增长明显。
