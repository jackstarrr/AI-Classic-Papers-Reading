## 问题背景

Transformer 在 NLP 中成功后，研究者尝试把同样结构迁移到视觉任务。

更具体地说，当时的核心困难是：已有方法在表达能力、可训练性、泛化能力、计算效率或数据利用方式上遇到了瓶颈。论文的贡献通常不是孤立的技巧，而是把一个关键瓶颈转化成可优化、可扩展、可验证的建模方案。

## 核心思想

把图像切成固定大小 patch，当作 token 序列输入 Transformer 编码器。

你可以把这篇论文的中心问题写成三个问题：

1. 输入是什么，模型要输出什么？
2. 中间表示或状态如何组织信息？
3. 训练信号如何推动这些表示变得有用？

## 模型/算法结构详解

每个 patch 线性投影为 embedding，加位置编码和 class token 后进入 Transformer。

ViT 把图像切成固定大小 patch，每个 patch 展平并线性投影成 token，再加位置编码输入 Transformer encoder。分类时使用 class token 或池化后的表示。

## 训练目标与优化方式

ViT 减少了 CNN 的局部卷积先验，因此更依赖大规模数据预训练。足够数据下，Transformer 的全局建模能力可以弥补先验不足，并获得强表现。

阅读公式时建议按“变量含义 -> 目标函数 -> 梯度/更新 -> 推理方式”的顺序拆解。不要急着记所有符号，先确认每个符号对应数据、参数、隐藏变量还是预测结果。

## 实验应该怎么看

读论文时注意数据规模对结果的影响：小数据上 ViT 未必优于 CNN，大规模预训练后才显著强。这个现象说明架构能力和数据规模要一起讨论。

读实验部分时，建议分三层看：

1. 主结果是否支持论文声称的核心贡献。
2. 消融实验是否证明关键组件真的有用。
3. 失败案例、限制和数据设置是否影响结论外推。

## 对 AI 体系结构的影响

ViT 证明在足够数据和算力下，纯 Transformer 可以成为强视觉 backbone。

它对后续工作的影响通常体现在两方面：一是直接成为后续模型的模块或训练范式；二是改变研究者提出问题的方式，让某类任务可以被更统一地建模。

## 局限与容易误解的地方

数据需求较高，小数据上不如 CNN 归纳偏置强，计算也随 token 数增长明显。

Patch 大小会影响 token 数和细节保留。标准 ViT 对高分辨率图像成本高，后续 Swin 等模型引入窗口和层级结构。
