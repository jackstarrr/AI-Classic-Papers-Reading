# 代码示例

对应论文：BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding

示例主题：演示 masked language modeling 数据构造

## 运行方式

在资料库根目录运行：

```bash
python3 23_bert_2018/code/run.py
```

也可以进入本论文目录后运行：

```bash
python3 code/run.py
```

## 说明

该示例是用于理解论文关键机制的最小可执行程序，不复现论文完整实验规模。公共实现位于资料库根目录的 `ai_paper_examples.py`，本目录的 `run.py` 是独立入口。
